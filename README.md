# Painel de Orçamento de Escapamento — AVUS

Painel estático (arquivo único `index.html`) publicado via GitHub Pages.

- A URL da ponte (Apps Script) e o token de escrita **não estão embutidos** neste
  repositório público: preencha os dois campos no card "Base viva" do próprio painel.
- A planilha da base continua privada — a ponte roda com a permissão do dono e
  exige token para qualquer escrita.
- Fonte da verdade do painel: `Desktop\AVUS - ESTEIRA XML\PAINEL DE ORCAMENTO (V8).html`
  (o parser da esteira reescreve o bloco de preços de compra lá; copiar para cá ao atualizar,
  removendo o token embutido).
